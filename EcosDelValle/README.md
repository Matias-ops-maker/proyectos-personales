# Ecos del Valle

**Ecos del Valle** es un proyecto personal que estoy haciendo para aprender a
crear un juego desde cero y sumar un proyecto propio a mi portfolio.

La idea es armar un pequeño pueblo habitado por personajes que tienen sus
propias rutinas, necesidades y recuerdos. Quiero que el jugador pueda cambiar
algo del entorno y ver cómo reaccionan los habitantes, además de poder entender
por qué cada uno tomó una decisión. No busco hacer un juego enorme: quiero
construir una demo chica, jugable y cada vez más completa mientras aprendo.

## Qué quiero practicar

- Crear un juego 2D con Godot y GDScript.
- Organizar escenas y código para que el proyecto pueda crecer.
- Programar personajes que se mueven y toman decisiones.
- Guardar partidas y mostrar información útil en la interfaz.
- Probar, corregir y documentar un proyecto de principio a fin.

## Cómo ejecutarlo

1. Instala Godot 4.
2. Abre Godot y elige **Importar**.
3. Busca y selecciona `project.godot` en esta carpeta.
4. Pulsa **F5** para ejecutar el proyecto.

Estoy usando GDScript, el lenguaje integrado de Godot. La extensión **Godot
Tools** para VS Code es opcional; también puedes editar y ejecutar todo desde
el editor de Godot.

## Estado

La pantalla inicial ya permite entrar al valle. Es una partida individual: tiene
casas, una plaza, una granja y Nexo Industrias, sin intercambios ni granjas de
otros jugadores. En seis parcelas se puede sembrar trigo, zanahoria y tomate,
esperar a que crezcan, cosecharlos y completar pedidos del mercado local para
ganar monedas. Los habitantes conservan sus necesidades, rutinas, trabajos y
relaciones; también se pueden seleccionar para consultar sus datos y darles
órdenes.

El pueblo y sus habitantes siguen siendo parte central de la historia. El foco
jugable ahora está en desarrollar una granja propia: sembrar, cosechar, reunir
recursos y completar pedidos de los comercios locales. La experiencia se plantea
para jugar en solitario, sin depender de conexión ni de granjas de otras
personas. Más adelante se irán sumando sistemas de producción y decoración.
